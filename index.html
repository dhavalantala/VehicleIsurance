01 · Overview

Problem Statement

An insurance company wants to identify which existing health insurance customers are likely to buy vehicle insurance as well. By building a predictive model, the company can prioritise outreach campaigns and personalise communication — reducing cost-per-acquisition and improving conversion rates.

The target variable Response is binary: 1 = interested, 0 = not interested. The dataset exhibits class imbalance, addressed via oversampling.

03 · EDA Highlights
⚖️

Class Imbalance Detected

The Response column shows a significant skew toward "not interested" (0). The notebook uses RandomOverSampler from imbalanced-learn to balance classes before modelling.

🚗

Vehicle Damage is a Strong Signal

Customers who previously had vehicle damage are significantly more likely to respond positively. Cross-tab analysis of Vehicle_Damage vs Response confirms this strong correlation.

🔒

Previously Insured → Low Interest

Customers who already hold vehicle insurance show near-zero positive response. This feature is highly discriminative and could serve as a hard filter before scoring.

📅

Older Vehicles Show Higher Intent

Vehicles aged > 2 years are associated with higher cross-sell interest, likely because owners feel more exposed to risk and are seeking coverage proactively.

👤

Gender Distribution is Roughly Even; Male Slightly Dominant

The dataset skews slightly male. Both genders show similar patterns relative to the response variable, making gender a lower-priority feature overall.

04 · ML Pipeline
01

Data Loading & Inspection

Loaded CSV into pandas, checked for nulls (none found), reviewed dtypes and descriptive stats with df.describe() and df.info().

02

Exploratory Data Analysis

Distribution plots for Age, Annual Premium, Response, Gender, Vehicle Age, and Vehicle Damage. Cross-tabs between Response and key categorical features using seaborn catplots.

03

Encoding & Feature Engineering

Gender binary-mapped (Female=0, Male=1). Vehicle_Age and Vehicle_Damage one-hot encoded via pd.get_dummies(drop_first=True). Columns renamed for clarity.

04

Scaling

StandardScaler applied to Age and Vintage (z-score). MinMaxScaler applied to Annual Premium (bounded distribution). ID column dropped.

05

Train / Test Split

75% train / 25% test split using train_test_split(random_state=0) for reproducibility.

06

Hyperparameter Tuning

Grid search using RandomizedSearchCV over criterion, max_depth, min_samples_leaf, min_samples_split, and n_estimators. 4-fold cross-validation.

07

Model Persistence

Final model serialised with pickle to rf_model.pkl for downstream serving or inference.

08 · Next Steps & Improvements
📊

Feature Importance Analysis

Extract and visualise feature_importances_ from the trained forest to understand which signals drive predictions most.

🔁

Try Gradient Boosting (XGBoost / LightGBM)

Ensemble boosting methods tend to outperform random forests on tabular classification tasks, especially with class imbalance.

🎯

Calibrate Probability Thresholds

For cross-sell campaigns, optimising the classification threshold for Precision–Recall trade-off (rather than default 0.5) can significantly improve business ROI.

🧪

SHAP Values for Explainability

Adding SHAP explanations makes the model interpretable to business stakeholders — critical for insurance where decisions must be justifiable.
